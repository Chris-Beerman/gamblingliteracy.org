## 1. Predict first

You roll a die and get the same number three times in a row. On the next roll, is that number:

<p class="choices">☐ more likely &nbsp;&nbsp; ☐ less likely &nbsp;&nbsp; ☐ just as likely &nbsp;&nbsp; to come up again?</p>

Why do you think so? <span class="blank full"></span>

## 2. Roll 60 times

Make a tally mark for each roll.

| Number | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| Tally | | | | | | |
| Total | | | | | | |

If every number is equally likely, each should come up about **10 times** out of 60. How close did you get? <span class="blank wide"></span>

## 3. Watch for streaks

Every time you roll the **same number twice in a row**, write down what you rolled **next**.

| Streak | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| Number rolled twice | | | | | | | | |
| Next roll | | | | | | | | |

Was the next roll the same number more often, less often, or about 1 time in 6?

<span class="blank full"></span>

## 4. Talk about it

- After a streak, did the die "remember"? What does that mean for the idea that a win is "due"?
- Where do people believe a win is due? Think about sports betting, slot machines and loot boxes.
- Why might "I'm due" keep someone betting after they've lost?

## No dice? Use a coin

Flip a coin 50 times. Write **H** or **T** in each box. Then circle every run of **three heads in a row** and look at the flip that came right after it.

::: practical "For the teacher"
Pool every pair's totals on the board. With a whole class, each number lands very close to one in six, and the roll after a streak behaves like any other roll. Individual pairs will vary, which is itself worth discussing: small samples look streaky. This is a practical classroom activity, not a tested intervention. The [conversation guide](/educators/conversation-guide/#activity) has the full context.
:::
